# 《新标日》初级上：基本功笔记

这份笔记按《新标日初级上》第 1—24 课整理。内容包括句子结构、谓语变化、动词各形、助词、指示词、数量表达和主要句型。先把这些内容看明白，再逐课学习时会容易得多。

## 1. 全册概要

初级上共有六个单元，每个单元四课。语法内容大致按下面的顺序展开。

| 单元   |    课次 | 主要内容                       |
| ---- | ----: | -------------------------- |
| 第一单元 |   1—4 | 名词句，指示词，地点，存在句             |
| 第二单元 |   5—8 | 动词礼貌体，时间，移动，动作对象，授受表达      |
| 第三单元 |  9—12 | 一类形容词，二类形容词，喜好与能力，比较       |
| 第四单元 | 13—16 | 数量词，动词 `て形`，请求、许可、禁止，动作与状态 |
| 第五单元 | 17—20 | 愿望，变化，动词 `ない形`、基本形，能力与习惯   |
| 第六单元 | 21—24 | 动词 `た形`，普通体，列举，转述，说明       |

前半册以简单句为主，后半册开始大量使用动词变形。第 22 课以后学习普通体，并用普通体组成较长的句子。

## 2. 语音和书写

### 2.1 拍

日语通常按“拍”来计算词的长度。一个假名一般占一拍，长音、促音 `っ` 和拨音 `ん` 也各占一拍。

| 词 | 分拍 | 拍数 |
|---|---|---:|
| がくせい | が・く・せ・い | 4 |
| がっこう | が・っ・こ・う | 4 |
| きょう | きょ・う | 2 |
| しんぶん | し・ん・ぶ・ん | 4 |

长短音不同，词义可能也不同。

- おばさん：阿姨
- おばあさん：奶奶、外婆
- ここ：这里
- こうこう：高中

### 2.2 促音、拨音和拗音

- 促音 `っ` 后面会有短暂停顿：`きて` 与 `きって` 不同。
- 拨音 `ん` 单独占一拍：`みんな = み・ん・な`。
- 拗音中的 `ゃ／ゅ／ょ` 要写小：`きゃ、しゅ、ちょ`。`きょう` 不能读成 `き・よ・う`。

### 2.3 助词的特殊读音

| 写法 | 作助词时的读音 | 例 |
|---|---|---|
| は | わ | わたし**は**学生です。 |
| へ | え | 日本**へ**行きます。 |
| を | お | 本**を**読みます。 |

## 3. 句子的基本结构

### 3.1 谓语一般放在句末

日语句子的最后通常是名词、形容词或动词。句末决定一句话是在判断、描写，还是叙述动作。

`わたしは　昨日　図書館で　日本語の本を　読みました。`

| 部分 | 作用 |
|---|---|
| わたしは | 以“我”为话题 |
| 昨日 | 时间 |
| 図書館で | 动作发生的地点 |
| 日本語の本を | 阅读的对象 |
| 読みました | 谓语：过去、肯定、礼貌体 |

中文可以说“我读了书”，日语也可以把时间、地点和对象放在前面，但谓语一般仍在句末。句中各部分的作用主要由助词表示，因此语序有一定弹性。

### 3.2 看句尾时注意四点

| 项目 | 可能的形式 | 例 |
|---|---|---|
| 词类 | 名词、一类形容词、二类形容词、动词 | 学生、高い、静か、食べる |
| 时间 | 非过去、过去 | 食べる、食べた |
| 肯否 | 肯定、否定 | 食べる、食べない |
| 语体 | 礼貌体、普通体 | 食べます、食べる |

日语的“非过去”可以表示现在的状态、经常发生的事，也可以表示将来的事。

- 毎朝、パンを食べます。每天早上吃面包。
- 明日、東京へ行きます。明天去东京。

### 3.3 话题和省略

`は` 表示这句话谈论的对象。上下文已经明确的主语、宾语等，日语中常常省略。

> 甲：コーヒーを飲みますか。要喝咖啡吗？  
> 乙：はい、飲みます。嗯，喝。

回答中没有重复“我”和“咖啡”，意思仍然清楚。

### 3.4 修饰语放在被修饰词前面

- 日本語**の**本：日语书
- おもしろい本：有趣的书
- 静かな町：安静的城市
- 昨日買った本：昨天买的书

## 4. 名词句和形容词句

### 4.1 名词句

#### 礼貌体

|  | 非过去 | 过去 |
|---|---|---|
| 肯定 | 学生です | 学生でした |
| 否定 | 学生ではありません | 学生ではありませんでした |

`では` 在日常会话中常说成 `じゃ`。

- 学生じゃありません。
- 学生じゃなかったです。

#### 普通体

|  | 非过去 | 过去 |
|---|---|---|
| 肯定 | 学生だ | 学生だった |
| 否定 | 学生ではない | 学生ではなかった |

名词句末的 `だ` 在随意会话中有时省略，但接 `と思います／と言います` 时通常保留。

- 李さんは学生だと思います。
- 森さんは会社員だと言いました。

### 4.2 一类形容词

一类形容词以可以变化的 `い` 结尾，如 `高い、暑い、おもしろい`。

#### 礼貌体

|  | 非过去 | 过去 |
|---|---|---|
| 肯定 | 高いです | 高かったです |
| 否定 | 高くないです | 高くなかったです |

较正式的否定也可以说：

- 高くありません。
- 高くありませんでした。

#### 普通体

|  | 非过去 | 过去 |
|---|---|---|
| 肯定 | 高い | 高かった |
| 否定 | 高くない | 高くなかった |

修饰名词时直接放在名词前：`高い山、おもしろい本`。

> **`いい` 的变化**
>
> `いい` 变化时按 `よい` 处理：`よくない、よかった、よくなかった`。

### 4.3 二类形容词

二类形容词又叫形容动词，如 `静か、便利、有名、きれい`。

#### 礼貌体

|  | 非过去 | 过去 |
|---|---|---|
| 肯定 | 静かです | 静かでした |
| 否定 | 静かではありません | 静かではありませんでした |

#### 普通体

|  | 非过去 | 过去 |
|---|---|---|
| 肯定 | 静かだ | 静かだった |
| 否定 | 静かではない | 静かではなかった |

修饰名词时加 `な`：`静かな町、便利な店`。

`きれい` 虽然以 `い` 结尾，却是二类形容词：

- きれいな花
- きれいではありません

### 4.4 名词和形容词的连接

| 词类 | 连接形式 | 例 |
|---|---|---|
| 一类形容词 | `～くて` | この料理は安くて、おいしいです。 |
| 二类形容词 | `～で` | この町は静かで、きれいです。 |
| 名词 | `～で` | 李さんは中国人で、会社員です。 |

## 5. 动词

### 5.1 三类动词

《新标日》把动词分为一类、二类和三类。

| 类别 | 特点 | 例 |
|---|---|---|
| 一类动词 | 基本形词尾在 `う段`，变化时词尾会改变 | 書く、話す、待つ、読む、帰る |
| 二类动词 | 多数以 `～いる／～える` 结尾，变化时通常去掉 `る` | 見る、起きる、食べる |
| 三类动词 | 不规则动词 | する、来る |

`～いる／～える` 只是大致规律。`帰る、入る、走る、切る、知る、要る` 等是一类动词，应当单独记住。

### 5.2 一类动词的变化

| 基本形词尾 | ます形 | ない形 | て形 | た形 | 例 |
|---|---|---|---|---|---|
| `う` | `います` | `わない` | `って` | `った` | 会う → 会います／会わない／会って／会った |
| `つ` | `ちます` | `たない` | `って` | `った` | 待つ → 待ちます／待たない／待って／待った |
| `る` | `ります` | `らない` | `って` | `った` | 帰る → 帰ります／帰らない／帰って／帰った |
| `ぬ` | `にます` | `なない` | `んで` | `んだ` | 死ぬ → 死にます／死なない／死んで／死んだ |
| `ぶ` | `びます` | `ばない` | `んで` | `んだ` | 遊ぶ → 遊びます／遊ばない／遊んで／遊んだ |
| `む` | `みます` | `まない` | `んで` | `んだ` | 読む → 読みます／読まない／読んで／読んだ |
| `く` | `きます` | `かない` | `いて` | `いた` | 書く → 書きます／書かない／書いて／書いた |
| `ぐ` | `ぎます` | `がない` | `いで` | `いだ` | 急ぐ → 急ぎます／急がない／急いで／急いだ |
| `す` | `します` | `さない` | `して` | `した` | 話す → 話します／話さない／話して／話した |

`て形／た形` 可以按四组记：

- `う・つ・る → って／った`
- `ぬ・ぶ・む → んで／んだ`
- `く → いて／いた`，`ぐ → いで／いだ`
- `す → して／した`

常见例外：

- 行く → 行きます／行かない／**行って／行った**
- ある → あります／**ない**／あって／あった

### 5.3 二类动词和三类动词

| 动词 | ます形 | ない形 | て形 | た形 |
|---|---|---|---|---|
| 食べる | 食べます | 食べない | 食べて | 食べた |
| 見る | 見ます | 見ない | 見て | 見た |
| する | します | しない | して | した |
| 来る | 来ます | 来ない | 来て | 来た |

`来る` 的读音会变化：`来る（くる）／来ます（きます）／来ない（こない）／来て（きて）／来た（きた）`。

### 5.4 ます形

动词礼貌体用 `ます`。四种基本形式如下。

|  | 非过去 | 过去 |
|---|---|---|
| 肯定 | 食べます | 食べました |
| 否定 | 食べません | 食べませんでした |

`ます形` 去掉 `ます` 后的部分叫动词词干，可接一些表达：

- 食べ**たいです**：想吃
- 飲み**ませんか**：要不要喝
- 行き**ましょう**：一起去吧

### 5.5 て形

| 句型 | 意思 | 例 |
|---|---|---|
| `Vて、V` | 动作依次发生 | 朝ご飯を食べて、会社へ行きます。 |
| `Vてから、V` | 做完前项再做后项 | 手を洗ってから、食べます。 |
| `Vてください` | 请做 | ここに名前を書いてください。 |
| `Vています` | 正在做；处于某种状态 | 本を読んでいます。結婚しています。 |
| `Vてもいいです` | 可以做 | ここで写真を撮ってもいいです。 |
| `Vてはいけません` | 不可以做 | ここでたばこを吸ってはいけません。 |

`Vています` 的意思和动词本身有关。

- 本を読んでいます：正在读书。
- 東京に住んでいます：住在东京。
- 結婚しています：已经结婚，目前处于已婚状态。
- 知っています：知道。

### 5.6 ない形

| 句型 | 意思 | 例 |
|---|---|---|
| `Vないでください` | 请不要做 | ここに車を止めないでください。 |
| `Vなければなりません` | 必须做 | 薬を飲まなければなりません。 |
| `Vなくてもいいです` | 不做也可以 | 明日は来なくてもいいです。 |

### 5.7 基本形

| 句型 | 意思 | 例 |
|---|---|---|
| `V（基本形）+ ことができます` | 能做 | ピアノを弾くことができます。 |
| `趣味は V（基本形）+ ことです` | 爱好是做某事 | 趣味は音楽を聞くことです。 |
| `V（基本形）+ 前に` | 做某事之前 | 寝る前に、歯を磨きます。 |

### 5.8 た形

| 句型 | 意思 | 例 |
|---|---|---|
| `Vたことがあります` | 有过某种经历 | 京都へ行ったことがあります。 |
| `Vた後で` | 做完某事以后 | ご飯を食べた後で、散歩します。 |
| `Vたほうがいいです` | 最好做 | もっと休んだほうがいいです。 |
| `Vたり Vたりします` | 列举若干动作 | 日曜日は掃除したり、買い物に行ったりします。 |

`Vました` 只说明过去发生过；`Vたことがあります` 表示“曾有过这种经历”。

一类形容词用 `～かったり`，二类形容词和名词用 `～だったり`：

- 季節によって、暑かったり寒かったりです。
- 先生だったり、学生だったりします。

### 5.9 普通体

|  | 非过去肯定 | 非过去否定 | 过去肯定 | 过去否定 |
|---|---|---|---|---|
| 食べる | 食べる | 食べない | 食べた | 食べなかった |

动词普通体可用于随意会话，也可放在 `と思います、と言いました、かどうか` 等表达前面。

- 明日は雨が降ると思います。
- 李さんは来ないと言いました。
- 森さんが来るかどうか分かりません。

## 6. 助词

### 6.1 常用助词

| 助词 | 主要用法 | 例 |
|---|---|---|
| `は` | 话题、对比 | わたし**は**学生です。 |
| `が` | 主体；存在、喜好、能力的对象 | 猫**が**います。日本語**が**分かります。 |
| `を` | 动作对象；经过或离开的场所 | 本**を**読みます。公園**を**散歩します。 |
| `に` | 时间、存在地点、到达点、对象、频率基准 | 7時**に**起きます。東京**に**着きます。 |
| `へ` | 移动方向 | 日本**へ**行きます。 |
| `で` | 动作地点、工具、方法、材料、人数状态 | 図書館**で**勉強します。バス**で**行きます。 |
| `と` | 共同者、完整列举、引用 | 友達**と**行きます。行く**と**言いました。 |
| `から` | 起点、来源、原因 | 9時**から**働きます。友達**から**もらいました。 |
| `まで` | 终点、截止时间 | 5時**まで**働きます。 |
| `の` | 所属、性质、内容等 | 日本語**の**本。 |
| `も` | 也；疑问词加否定时表示全部否定 | わたし**も**学生です。何**も**食べません。 |
| `か` | 疑问、选择、不确定 | 行きます**か**。パン**か**おにぎり。 |
| `や` | 不完全列举 | 野菜**や**果物を買いました。 |
| `より` | 比较的基准 | 日本は中国**より**狭いです。 |

### 6.2 `は` 和 `が`

`は` 提出话题，`が` 指出动作或状态的主体。回答“谁”“什么”时，未知部分通常用 `が`。

> だれが来ましたか。  
> 李さんが来ました。

存在句中，存在的事物用 `が`；把已经说过的事物作为话题时用 `は`。

- 部屋に机**が**あります。
- 机**は**部屋にあります。

以下表达的对象常用 `が`：`好きです／嫌いです／上手です／下手です／分かります／できます／欲しいです`。

例：`小野さんは歌が上手です。`

### 6.3 `に` 和 `で`

- `に` 表示人或事物存在的地点：`部屋に猫がいます。`
- `で` 表示动作发生的地点：`部屋で本を読みます。`

`いる／ある` 用 `に`，普通动作通常用 `で`。

### 6.4 `に`、`へ` 和 `を`

- `に`：到达点。`学校に着きます。`
- `へ`：移动方向。`学校へ行きます。`
- `を`：经过或离开的地点。`橋を渡ります。家を出ます。`

`行く／来る／帰る` 的目的地可以用 `に` 或 `へ`。`に` 更偏向到达点，`へ` 更偏向方向。

### 6.5 授受表达中的助词

#### あげます

`A は B に 物を あげます`：A 给 B 某物。

`わたしは小野さんにお土産をあげました。`

#### もらいます

`A は B に／から 物を もらいます`：A 从 B 那里得到某物。

`わたしは小野さんに／から辞書をもらいました。`

### 6.6 时间后面的 `に`

表示具体时刻时通常加 `に`。

- 7時に起きます。
- 5月1日に日本へ行きます。

表示相对时间或有规律重复的时间时，常常不用 `に`。

- 今日行きます。
- 毎日勉強します。
- 先週帰りました。

星期后面的 `に` 可用可不用：`日曜日（に）映画を見ます。`

## 7. 指示词和疑问词

### 7.1 こ・そ・あ・ど

| 类别 | 近说话人 | 近听话人 | 远离双方 | 疑问 |
|---|---|---|---|---|
| 事物 | これ | それ | あれ | どれ |
| 修饰名词 | この | その | あの | どの |
| 地点 | ここ | そこ | あそこ | どこ |
| 方向、较礼貌的地点或人物 | こちら | そちら | あちら | どちら |

`これ／それ／あれ／どれ` 可以单独使用；`この／その／あの／どの` 后面必须接名词。

- これは辞書です。
- この辞書はわたしのです。
- 日本語の辞書はどれですか。
- どの辞書が日本語の辞書ですか。

### 7.2 常用疑问词

| 想问的内容 | 疑问词 | 例 |
|---|---|---|
| 人 | だれ／どなた | だれが来ますか。 |
| 事物 | 何（なに／なん） | 何を食べますか。 |
| 地点 | どこ | どこで勉強しますか。 |
| 时间 | いつ／何時 | いつ行きますか。 |
| 选择 | どれ／どの + 名词 | どれがあなたの傘ですか。 |
| 性质 | どんな + 名词 | どんな町ですか。 |
| 状态、意见、方式 | どう | 旅行はどうでしたか。 |
| 原因 | どうして | どうして休みましたか。 |
| 价格 | いくら | これはいくらですか。 |
| 数量、年龄 | いくつ | りんごはいくつありますか。 |
| 时长、程度 | どのぐらい | どのぐらい勉強しましたか。 |

### 7.3 疑问词的固定组合

- `疑问词 + も + 否定`：全部否定。`何も食べません。だれもいません。`
- `疑问词 + でも`：任意一个。`何でもいいです。`
- `疑问词 + か`：不确定的人、物、时间或地点。`だれか来ました。`

## 8. 数量和时间

### 8.1 数量词的位置

数量词通常放在动词前面，不加助词。

- りんごを三つ買いました。
- 教室に学生が二十人います。

数量词也可以用 `数量 + の + 名词`：`三つのりんご、二十人の学生`。

表示频率时用 `时间范围 + に + 次数`：

- 一週間に二回泳ぎます。
- 一年に一回旅行します。

表示动作持续多长时间时，一般不加 `に`：`毎日二時間勉強します。`

### 8.2 常用量词

| 量词 | 用于 | 例 |
|---|---|---|
| `～つ` | 一般物品，通常数到十 | ひとつ、ふたつ、みっつ |
| `～人` | 人 | 一人（ひとり）、二人（ふたり）、三人（さんにん） |
| `～本` | 细长物 | 一本（いっぽん）、三本（さんぼん）、六本（ろっぽん） |
| `～枚` | 扁平物 | 紙を二枚 |
| `～冊` | 书、本子 | 本を三冊 |
| `～台` | 机器、车辆 | 車を一台 |
| `～個` | 小件物品 | 卵を六個 |
| `～杯` | 杯、碗 | コーヒーを一杯 |
| `～回` | 次数 | 一回、三回 |
| `～階` | 楼层 | 一階（いっかい）、三階（さんがい） |
| `～歳` | 年龄 | 一歳（いっさい）、八歳（はっさい）、二十歳（はたち） |

## 9. 常用句型

### 9.1 判断、指示和存在

| 句型 | 意思 | 例 |
|---|---|---|
| `A は B です` | A 是 B | 李さんは中国人です。 |
| `A は B ではありません` | A 不是 B | 森さんは学生ではありません。 |
| `A は B ですか` | A 是 B 吗 | 小野さんは会社員ですか。 |
| `A の B` | 所属、性质、内容等 | 日本語の本 |
| `地点に 物があります` | 某处有某物 | 机の上に本があります。 |
| `地点に 人／动物がいます` | 某处有人或动物 | 部屋に猫がいます。 |
| `物／人は 地点にあります／います` | 某物或某人在某处 | 李さんは教室にいます。 |

### 9.2 移动和动作

| 句型 | 例 |
|---|---|
| `时间に 动词` | 7時に起きます。 |
| `地点へ／に 行きます・来ます・帰ります` | 来月、日本へ行きます。 |
| `交通工具で 移动动词` | 電車で会社へ行きます。 |
| `人と 动词` | 友達と映画を見ます。 |
| `地点で 动词` | 図書館で勉強します。 |
| `对象を 动词` | コーヒーを飲みます。 |
| `工具／语言で 动词` | 日本語で手紙を書きます。 |

### 9.3 喜好、能力和愿望

| 句型 | 意思 | 例 |
|---|---|---|
| `N が好きです` | 喜欢 | わたしは音楽が好きです。 |
| `N が上手です` | 擅长 | 小野さんは料理が上手です。 |
| `N が分かります` | 懂 | 日本語が分かります。 |
| `N ができます` | 会；能够；完成 | 李さんは料理ができます。 |
| `N が欲しいです` | 想要某物 | 新しいかばんが欲しいです。 |
| `Vます（去掉ます）+ たいです` | 想做某事 | 日本へ行きたいです。 |

`たい` 按一类形容词变化：`行きたくない、行きたかった`。

### 9.4 邀请和提议

- `Vませんか`：要不要一起做。`いっしょに映画を見ませんか。`
- `Vましょう`：一起做吧。`少し休みましょう。`
- `Vましょうか`：我来做吧；要不要一起做。`荷物を持ちましょうか。`

### 9.5 变化和人为决定

| 句型 | 意思 | 例 |
|---|---|---|
| `一类形くなります` | 变得…… | 暖かくなりました。 |
| `二类形／名になります` | 变成…… | 元気になりました。医者になりました。 |
| `一类形くします` | 使其变得…… | テレビの音を大きくします。 |
| `二类形／名にします` | 使其成为；决定选 | 部屋をきれいにします。コーヒーにします。 |

`なります` 侧重变化的结果，`します` 侧重人为改变或选择。

### 9.6 比较

| 句型 | 例 |
|---|---|
| `A は B より ～です` | 中国は日本より広いです。 |
| `A より B のほうが ～です` | 北京より東京のほうが暖かいです。 |
| `A と B と どちらが ～ですか` | 日本語と英語とどちらが難しいですか。 |
| `范围の中で X がいちばん ～です` | スポーツの中でサッカーがいちばん好きです。 |

### 9.7 连接句子

- 动词：`Vて、V`。`朝ご飯を食べて、学校へ行きます。`
- 一类形容词：`～くて`。`この店は安くて、おいしいです。`
- 二类形容词、名词：`～で`。`京都は静かで、きれいです。`
- 原因：`～から`。`寒いですから、窓を閉めます。`
- 转折：`～が／けど`。`この店は高いですが、おいしいです。`

### 9.8 小句

普通体可以放在另一个表达前面，组成较长的句子。

#### `～と思います`

表示说话人的想法或判断。

- 明日は雨が降ると思います。
- 李さんは来ないと思います。
- この町は静かだと思います。

#### `～と言います／言いました`

表示转述。直接引用时也可用 `「……」と言いました`。

- 森さんは明日休むと言いました。
- 李さんは「また来ます」と言いました。

#### `～かどうか`

把“是否……”放进句子。

- 森さんが来るかどうか分かりません。
- この料理が辛いかどうか知りません。

带疑问词时不用 `かどうか`，直接用 `疑问词小句 + か`。

- だれが来るか分かりません。
- いつ出発するか教えてください。

#### `～のです／んです`

用于说明情况、补充原因，或询问事情的缘由。口语中常用 `んです`。

- 頭が痛いんです。
- どうして遅れたんですか。

名词和二类形容词前用 `な`：`学生なんです。この町は静かなんです。`

## 12.如何使用

这份 PDF 建议用三遍：先通读全册结构，再专门练变形，最后配合教材逐课查阅。它不是用来从第一页背到最后一页的，也不能代替课文。

这和[豆瓣帖](https://book.douban.com/review/9585357/)的顺序基本一致：先弄清初级上反复出现的规则，练熟词形变化，然后再回到第一课正式学习。

### 第一遍：看懂全册在讲什么

按这个顺序阅读：

1. `全册概要`
2. `句子的基本结构`
3. `名词和形容词`
4. `动词`
5. `助词`
6. `指示词和疑问词`
7. `数量和时间`
8. `常用句型`

你已经比较熟悉五十音，所以“语音和书写”只需看看长音、促音、拨音、拗音，以及助词 `は／へ／を` 的特殊读音。

第一遍不要背表格，也不用重新抄笔记。主要弄清下面几件事：

* 日语的谓语通常放在句末。
* 句末可能是名词、形容词或动词。
* 句尾会表示时间、肯否和语体。
* 助词说明句中各部分的作用。
* 后半册的大部分语法都建立在动词变形上。

看到暂时不理解的句型，可以继续往后读。第一遍的目的只是知道它是什么、以后会在哪里出现。

### 第二遍：集中练变形

这是豆瓣帖所说的“基本功”中最重要的部分，主要使用 PDF 的“名词和形容词”和“动词”两章。

先熟悉四类谓语的基本变化：

* 名词
* 二类形容词
* 一类形容词
* 动词

看到一个句尾，应当能分辨：

* 非过去还是过去
* 肯定还是否定
* 礼貌体还是普通体

然后重点练动词。每遇到一个教材中的常用动词，依次说出：

> 类别 → ます形 → 基本形 → ない形 → て形 → た形

例如：

> 行きます → 行く → 行かない → 行って → 行った

> 食べます → 食べる → 食べない → 食べて → 食べた

> 来ます → 来る → 来ない → 来て → 来た

不必另外找很长的动词表。直接使用《新标日》各课词汇里的动词，每天拿十几个练习即可。遇到不会的，再回到 PDF 的动词变化表查看。

这一阶段尤其要留意：

* 一类、二类、三类动词的判断
* `う・つ・る → って`
* `ぬ・ぶ・む → んで`
* `く → いて`
* `ぐ → いで`
* `す → して`
* `行く`、`ある` 等例外
* `来る` 在各种形式中的读音变化

### 第三遍：回到第一课逐课学习

完成前面的通读和变形练习后，再开始第 1—24 课。

每学一课，可以这样使用 PDF：

1. 先看“第 1—24 课内容速查”，知道本课主要出现什么。
2. 阅读教材的基本课文和应用课文。
3. 遇到变化形式，先还原成原来的词。
4. 不清楚时，再去 PDF 对应章节查表。
5. 查明以后马上回到课文，不要长时间停留在表格里。

例如看到：

> 名前を書いてください。

先认出：

* `書いて` 来自 `書く`
* 使用的是 `て形`
* `Vてください` 表示请求

看到：

> 京都へ行ったことがあります。

先认出：

* `行った` 来自 `行く`
* 使用的是 `た形`
* `Vたことがあります` 表示经历

这样，句型就不再是需要整块死记的内容，而是“动词形式＋后续表达”。

如果严格按照帖子的方法，第一次逐课阅读时可以把重点放在课文上，不必把每道练习都做完。课文中的生词优先记，尤其是动词和副词；练习里单独出现、课文没有用到的词，可以稍后再处理。

### 什么时候算完成“基本功”

达到下面的程度，就可以按帖子所说的方式回到第一课：

* 能从句尾判断谓语属于哪一类。
* 能看出句子的时间、肯否和语体。
* 给出一个常用动词，能判断类别并说出基本形、ない形、て形和た形。
* 看到变化后的动词，能大致还原原形。
* 知道常用助词在句中大致表示什么。
* 知道普通体可以接在 `と思います`、`と言います`、`かどうか` 等表达前面。

不要求此时已经记住 PDF 里的每个句型。帖子中“再回过头，从第一课看到最后一课”的前提，主要就是已经看懂这些共同规则，尤其是谓语和动词的变化。

一句话概括：**先用 PDF 看清全册结构并练熟变形；开始逐课学习后，把它放在旁边当查阅手册。** “10 天”只是原帖给出的较快进度，不需要把它当成硬性期限。
